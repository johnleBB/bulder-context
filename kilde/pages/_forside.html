For designere

Komponentene ligger i Figma-biblioteket Bulder library. Bruk komponentene og tokenene derfra, ikke egne farger eller tekststørrelser.

  • Design for en telefon som er 375 px bred, med Header øverst. Skjermer på toppnivå slutter med BottomNavigation.
  • Navngi farger etter token, for eksempel On_Surface, ikke etter hvordan de ser ut.
  • Én primærknapp per skjerm.

For utviklere

Kilden er repoet bulderbank/DesignSystem. Generatoren DSCodegen lager pakker for iOS og Android av tokens, ikoner, bilder og animasjoner. Alle tokens og ikoner kan du også se i token-browseren.

iOS

En Swift Package for iOS 16 og nyere, med farger og bilder i .xcassets, typografi og animasjoner. Pakken gir deg verdiene. Fontregistrering, Dynamic Type og Lottie-avspilling har appen selv ansvar for.

// Package.swift
      .package(url: "https://github.com/bulderbank/DesignSystem", from: "1.0.139")

      // I koden
      import DesignSystem

      let heading = DS.Typography.App.h1
      let size = heading.fontSize
      let tracking = heading.fontSize * heading.letterSpacing
      let animation = DS.Animation.checkmark.url

Android

Et Compose-bibliotek for Android 6.0 (API 23) og nyere, med pakkenavnet no.bulder.bank.designsystem. Det har fargene som Material 3-fargeskjema for light og dark mode, et ekstra fargeskjema for Bulder-fargene som ikke finnes i Material 3, og ikonene som VectorDrawables.

MaterialTheme(
          colorScheme = if (isSystemInDarkTheme()) Theme.DarkColors else Theme.LightColors
      ) {
          // innholdet ditt
      }

Pakken publiseres til Google Artifact Registry (europe-west1-maven.pkg.dev/bulder-shared/bulder-android-maven).
