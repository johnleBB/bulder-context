Repoet

Koden ligger i bulderbank/DesignSystem. Repoet har tokens (farger, typografi og spacing), ikoner som SVG, bilder og Lottie-animasjoner. Generatoren DSCodegen lager pakker for iOS og Android av dem.

Versjoner

Nye versjoner lages automatisk når en pull request merges til main:

1

DSCodegen genererer pakkene for iOS og Android.

2

Neste versjonsnummer regnes ut, for eksempel fra 1.0.139 til 1.0.140.

3

De genererte filene legges på grenen automation/<versjon>, og versjonen tagges.

4

Android-pakken publiseres. iOS-appen henter den nye taggen med Swift Package Manager.

Token-browseren på bulderbank.github.io/DesignSystem oppdateres når main endres.

Bygg og test lokalt

# Generer alt (krever Swift, ImageMagick og Java)
swift run DSCodegen

# Eller i en container med Podman eller Docker
./scripts/codegen-container.sh

# Token-browseren, skrives til site/
python3 scripts/generate_site.py

# Tester på macOS
swift test

Asset-katalogen for iOS kan bare kompileres på macOS med Xcode. Kjør scripts/validate_ios.sh der.

Kodestil

  • Tokenfiler har beskrivende og stabile navn, for eksempel Bulder colors.Light.tokens.json.
  • Ikoner er SVG.
  • Lottie-filer har navn i lowerCamelCase, likt navnene i Figma.
  • Hold endringer til ASCII-tegn, med mindre filen allerede har andre tegn.
